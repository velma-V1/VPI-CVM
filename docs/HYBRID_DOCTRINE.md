# VPI-CVM Hybrid Doctrine — Superseded Architecture Note

Status: **historical**.

This document previously governed the transition from the original evidence-driven software-engineering chassis toward project intelligence, adaptive verification, failure compilation, and verified skill accumulation.

Its useful mechanisms have been incorporated into [`ARCHITECTURE.md`](ARCHITECTURE.md) and [`PLAN.md`](PLAN.md). Where this historical note conflicts with Architecture v1, **Architecture v1 is authoritative**.

## Ideas retained in Architecture v1

- closed-loop model routing rather than a one-shot static router;
- local and frontier compute as replaceable lanes rather than permanent winners;
- adaptive verification driven by evidence/risk;
- failure compilation into reusable structured counterexamples;
- verified skill compilation with replay, holdouts, invalidation, and rollback;
- explicit fingerprints for reusable neural/context state;
- no automatic online LoRA from every accepted result;
- no unbounded background generation without measurable objectives;
- empirical promotion rather than vendor benchmark authority.

## Ideas corrected or expanded later

Architecture v1 now additionally requires:

- explicit resident intelligence independent of model/KV state;
- immutable world/project snapshots;
- independent Context Compiler;
- Living Arena **plus** sealed/rotating evaluation;
- adversarial counterexample search with deterministic arbitration;
- separate correctness, goal-conformance, and quality planes;
- realized-value recording before learned economic optimization;
- domain-specific world models and evidence-backed cross-domain transfer research;
- explicit independence between VPI-CVM and V31M4.

The Git history preserves the full original doctrine if historical detail is needed.
