# ADR 0003 — Integrate mature systems before reimplementing them

**Status:** Accepted

## Decision

VPI-CVM will not become another monolithic agent/runtime/workflow platform. Where contracts fit:

- OpenHands is the preferred richer coding-agent backend candidate.
- Temporal is the preferred long-duration durable-workflow backend candidate.
- VPI-CVM retains project truth, evidence, policy, provenance and acceptance authority.

## Consequences

Development effort concentrates on the gap existing systems do not own: supervisory project intelligence and evidence-governed acceptance.
